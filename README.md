# Parramatta Explorer — Landing Page

A single-page marketing / submission site for **Parramatta Explorer**, an accessible event-planning prototype for the City of Parramatta.

Built for **WSTI Festi 2026 — City Challenge 2: Better Community Events and Public Spaces**.

## What's here

- `index.html` — the landing page for the challenge submission. Open `index.html` in a browser to view the page.


## Live prototype

https://parramatta-explore.vercel.app

## Sections

The page follows the required submission structure: the problem and who it affects, how the product works (before / during / after), community benefit and how it's measured, tester feedback, data sources, privacy and responsible AI, Council's role (partner + advocate), fit with Council plans, and the next step.
